# Swift Ride - Premium & Minimalist Car Rental Website

Swift Ride adalah platform website rental mobil premium dengan antarmuka yang modern, minimalis, dan sangat responsif. Platform ini dibangun untuk memberikan pengalaman penyewaan armada terbaik dengan proses verifikasi instan dan keterbukaan harga tanpa biaya tersembunyi.

## 🚀 Fitur Utama
*   **Desain Premium & Minimalis:** Responsif di berbagai perangkat (seluler, tablet, hingga desktop).
*   **Pondasi Modular PHP:** Header dan footer dipisahkan secara modular untuk mempermudah pengembangan masa depan.
*   **Database Dinamis:** Terintegrasi dengan MySQL menggunakan PDO dengan penanganan koneksi yang aman.
*   **Smart Fallback:** Jika database tidak terhubung, website secara otomatis memuat data dummy premium secara mulus tanpa memicu kegagalan sistem.
*   **Keamanan Lingkungan:** Menggunakan pengelola variabel lingkungan (`.env`) bawaan PHP untuk melindungi kredensial database lokal.

## 🛠️ Stack Teknologi
*   **Frontend:** HTML5, TailwindCSS (Play CDN), Vanilla JavaScript.
*   **Backend:** PHP (Vanilla), MySQL.
